1 Identitas Produk

AtributKeterangan
Nama ProdukTixKita
Tentang ProdukTixKita adalah platform pemesanan tiket event dan travel kit berbasis web. Sistem ini memungkinkan pengguna menjelajahi event, membeli tiket secara online, dan melakukan check-in menggunakan QR Code. Platform ini juga menyediakan panel admin untuk organizer dalam mengelola event, pesanan, dan keuangan.
Versi Guideline1.0
PlatformWeb Application (Desktop & Mobile Responsive)
TujuanDokumen ini menjadi "bahasa bersama" tim desain dan developer agar tampilan aplikasi TixKita konsisten, mudah digunakan, dan dapat dikembangkan secara efisien di seluruh halaman dan fitur.

7 Do & Don't

✅ Do — Lakukan

  1. Gunakan CSS Variables (--primary-color, --secondary-color) untuk semua warna brand agar tetap dinamis.
  2. Gunakan Inter untuk halaman publik dan Nunito untuk admin panel secara konsisten.
  3. Event card selalu menggunakan border-radius 12px dan efek hover translateY(-5px).
  4. Status badge selalu menggunakan warna soft (background pastel + teks gelap), bukan warna solid Bootstrap.
  5. Gunakan SweetAlert2 Toast untuk semua notifikasi sukses/error, bukan alert HTML biasa.
  6. Sidebar admin selalu menggunakan gradient vertical dari Primary ke Secondary.
  7. Gunakan Font Awesome 6 untuk semua icon secara konsisten.
  8. Navbar publik harus sticky-top agar selalu terlihat saat scroll.
  9. Search bar menggunakan background #f8f9fa (bg-light) tanpa border untuk tampilan clean.
  10. Setiap halaman admin membungkus konten dalam card dengan shadow standar.

❌ Don't — Jangan

  1. Jangan hard-code warna primary/secondary — selalu gunakan CSS variable agar tetap bisa dikonfigurasi admin.
  2. Jangan gunakan font di luar Inter dan Nunito; dua font ini adalah standar yang diizinkan.
  3. Jangan gunakan Bootstrap alert bawaan untuk notifikasi; selalu gunakan SweetAlert2.
  4. Jangan mengubah lebar sidebar dari 250px; dimensi ini sudah dikalibrasi.
  5. Jangan menggunakan badge warna solid (bg-success/danger) — gunakan varian soft (bg-soft-success).
  6. Jangan mengubah border-radius event card dari 12px; ini adalah identitas visual card TixKita.
  7. Jangan membuat card admin dengan border visible — gunakan border: none dan shadow sebagai pembatas.
  8. Jangan mengubah hamburger icon animation — animasi X sudah dikalibrasi dengan timing yang tepat.
