# 🙋 Customer Guide

## Panduan Lengkap untuk Customer TixKita

---

## 1. Akun Customer

### 1.1 Membuat Akun

1. Klik tombol **"Daftar"** di pojok kanan atas
2. Isi formulir pendaftaran:
   - Nama lengkap
   - Email (akan digunakan untuk login)
   - Nomor HP
   - Password (minimal 8 karakter)
3. Klik **"Daftar"**
4. Cek email untuk kode OTP
5. Masukkan kode OTP di halaman verifikasi
6. Akun Anda siap digunakan!

### 1.2 Login

1. Klik **"Masuk"** di menu
2. Masukkan email dan password
3. Klik **"Login"**

### 1.3 Dashboard Customer

Setelah login, Anda dapat mengakses:
- **Profil** - Lihat data akun
- **Order History** - Riwayat pembelian
- **Tiket Aktif** - Tiket event mendatang

---

## 2. Membeli Tiket

### 2.1 Memilih Event

#### Dari Homepage
- Browse event di kalender atau list
- Gunakan filter kategori (Music, Seminar, dll)
- Klik pada event untuk melihat detail

#### Fitur Pencarian
- Gunakan kotak pencarian
- Ketik nama event atau lokasi
- Tekan Enter untuk mencari

### 2.2 Halaman Detail Event

Informasi yang tersedia:
- 📅 Tanggal dan waktu
- 📍 Lokasi venue
- 📝 Deskripsi event
- 💰 Daftar tiket dan harga
- 🎁 Bundle (jika tersedia)

### 2.3 Menambah ke Keranjang

1. Pilih jenis tiket
2. Tentukan jumlah (sesuai batas maksimal)
3. Klik **"Tambah ke Keranjang"**
4. Notifikasi sukses akan muncul

### 2.4 Keranjang Belanja

- Lihat semua item yang dipilih
- Ubah jumlah tiket
- Hapus item yang tidak jadi dibeli
- Lihat subtotal dan total
- Lanjut ke checkout

## 3. Proses Checkout

### 3.1 Form Data Pembeli

| Field        | Keterangan                |
| ------------ | ------------------------- |
| Nama Lengkap | Nama sesuai KTP           |
| Email        | Email aktif untuk tiket   |
| No. HP       | Nomor yang bisa dihubungi |

### 3.2 Data Peserta Tiket

*Diisi jika event memerlukan data per tiket*

| Field         | Keterangan             |
| ------------- | ---------------------- |
| Nama Peserta  | Nama yang akan masuk   |
| Email Peserta | Email peserta          |
| Data Tambahan | Sesuai kebutuhan event |

### 3.3 Kode Promo

1. Masukkan kode di kolom "Kode Promo"
2. Klik **"Gunakan"**
3. Diskon akan langsung teraplikasi

### 3.4 Ringkasan Pesanan

Pastikan semua benar:
- Daftar tiket
- Subtotal
- Diskon (jika ada)
- Pajak (jika ada)
- **Total Bayar**

### 3.5 Pilih Pembayaran

| Metode          | Deskripsi                    |
| --------------- | ---------------------------- |
| Virtual Account | Transfer ke rekening virtual |
| QRIS            | Scan QR dengan e-wallet      |

## 4. Pembayaran

### 4.1 Virtual Account

**Bank yang tersedia:**
- BCA VA
- BNI VA
- BRI VA
- Mandiri Bill
- Permata VA

**Cara Bayar:**
1. Catat nomor VA yang tampil
2. Buka mobile banking
3. Pilih menu Transfer > Virtual Account
4. Masukkan nomor VA
5. Konfirmasi nominal
6. Masukkan PIN
7. Simpan bukti transfer

### 4.2 QRIS

1. Buka aplikasi e-wallet (GoPay, OVO, DANA, dll)
2. Pilih **Scan QR**
3. Arahkan kamera ke QR code
4. Konfirmasi pembayaran
5. Masukkan PIN

### 4.3 Batas Waktu

⚠️ **Selesaikan pembayaran sebelum expired!**

- Batas waktu: 1-24 jam (tergantung metode)
- Setelah expired, pesanan otomatis dibatalkan
- Tiket dikembalikan ke stok

---

## 5. Menerima Tiket

### 5.1 Setelah Pembayaran Berhasil

Anda akan menerima:
1. **Email Konfirmasi** dengan:
   - Detail pesanan
   - PDF tiket dengan QR code
   - Link ke invoice online

2. **Halaman Invoice** dengan:
   - Order ID
   - Status pembayaran
   - Tombol download tiket

### 5.2 Download Tiket

1. Buka email konfirmasi
2. Klik attachment PDF atau
3. Klik link "Download Tiket"
4. Simpan PDF ke HP/laptop

---

## 6. Menggunakan Tiket

### 6.1 Persiapan

- ✅ Pastikan baterai HP cukup
- ✅ Download PDF sebagai backup
- ✅ Screenshot QR code jika perlu
- ✅ Datang tepat waktu

### 6.2 Di Venue

1. Tunjukkan QR code ke petugas
2. Tunggu proses scan
3. Setelah valid, silakan masuk

### 6.3 Tiket Sudah Digunakan

- Setiap tiket hanya bisa digunakan **1x**
- Setelah scan, status berubah menjadi "Used"
- Tidak bisa digunakan lagi

---

## 7. Troubleshooting

### Email Tiket Tidak Masuk

1. Cek folder **Spam/Junk**
2. Tunggu 5-10 menit
3. Cek History untuk download ulang
4. Hubungi support jika masih bermasalah

### Pembayaran Gagal

1. Pastikan saldo mencukupi
2. Cek batas transaksi harian
3. Coba metode pembayaran lain
4. Ulangi order jika perlu

### QR Code Tidak Terbaca

1. Tingkatkan kecerahan layar HP
2. Gunakan versi PDF
3. Minta bantuan petugas
